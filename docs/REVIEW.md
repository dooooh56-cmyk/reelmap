# 최종 코드 검토

검토 기준: 정확성, 단순성, 구조, 보안, 성능. `code-review-and-quality` 적용.

## 수정한 문제

- 주소 부분 문자열 비교가 6번지/60번지 또는 다른 시·구를 같은 장소로 볼 수 있는 문제: 도로/지번 숫자 경계와 지역 모두 검사하도록 수정.
- 외부 AI가 자료에 없는 주소를 생성해도 자동 저장 근거로 쓰지 않도록 원문 근거 검사 추가.
- 지도 키가 없을 때 자동 저장 뒤 외부 지도 창을 열던 문제: 자동 저장은 목록에만 반영하고 링크 열기는 사용자 동작으로 제한.
- Gemini 402에서도 명시 본문 규칙 추출로 전환하되 영상·음성 분석 성공으로 표시하지 않도록 수정.
- 재분석/직접 연결 성공 후 확인 필요 항목을 해제하도록 처리.
- 웹 탭 버튼에 키보드 좌우/Home/End 이동, roving tabindex, 패널 연결 추가.
- 요청 대상 URL 제한, JSON/텍스트/영상 용량 제한, Origin/체험 코드, HTML 출력 이스케이프 확인.
- 비밀 설정은 제출 소스·Git·압축 파일에서 제외.

- 실제 Cloudflare 환경에서 redirect:error 미지원 문제를 발견해 manual 이동 검사로 수정하고 회귀 검사를 추가함.
- 실제 카카오 검색 결과의 무관한 식당을 이름으로 걸러 후보의 일치 항목을 먼저 표시함.

## 남은 제한

실제 AI 성공·영상 이해 정확도·공유 확장 실기기 서명은 검증을 통과한 것으로 취급하지 않음. 실제 카카오 검색·지도 저장 및 iOS SDK 시뮬레이터용 빌드는 통과함. 자세한 내용은 VERIFICATION.md.

UI는 입력 이름/근거/주소가 우선이며 390px 가로 넘침을 검사함. VoiceOver·실제 Dynamic Type AX5·실기기 위치 권한·실제 지도 SDK는 미검증이므로 전체 접근성 합격으로 주장하지 않음.

## 재개 후 iOS 보완

App Group 식별자와 빌드 설정 연결, 분석 화면 중복 onAppear 방지, 제출 당시 입력으로 실패 기록, 공유된 본문 보존을 수정함. 실제 SDK 빌드와 시뮬레이터 앱 실행·지도 표시 확인. App Group 실기기 서명과 공유 저장은 아직 검증하지 못함.

## 본문 우선 처리 검토

추가 AI 요청은 본문 정보가 부족한 경우에만 수행. Kakao 오류 또는 Gemini 장애에서는 불필요한 후속 요청을 생략. 두 단계의 검색 결과는 요청 안에서만 재사용하고, 근거가 충돌하는 주소는 덮어쓰지 않고 선택 대상으로 남김. 제공자 usageMetadata는 JSON 결과가 잘못돼도 이미 사용된 측정 토큰에 포함. 사용자 제공 본문/파일이 있으면 인스타 접근을 반복하지 않음.
