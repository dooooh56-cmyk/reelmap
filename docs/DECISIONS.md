# 릴맵 결정사항

2026-10-30, 제출 2026-10-31 (한국 시간)

- 제품: 한국 맛집 릴스를 공유해 저장하고 내 주변에서 다시 찾는 개인 지도.
- iOS: 기본 네이티브 SwiftUI, 지도는 사용자 선택에 따라 카카오 지도.
- 웹: 평가자용 링크 접속, 링크 붙여넣기/파일 첨부, 로그인 없음, 브라우저 로컬 저장.
- 1곳이며 이름과 주소가 유일하게 일치하면 자동 저장. 여러 식당/불확실한 지점은 리스트에서 선택.
- 본문, 사진 글자, 영상 자막/음성 분석. 릴스 우선. Gemini 사용.
- 가져오기 실패 시 본문/캡처/영상 추가. 이후 직접 검색해 연결.
- 비용 한도 10,000원. 무료 할당량 우선, 자동 유료 전환 없음. API 제공자 한도 설정 필요.
- 완료 판단: 처음 보는 게시물을 실제로 분석하고 식당 위치를 검증하는 것이 최우선.

## UI 결정
- 지도와 목록을 나란히 둔 map-table 구조. 모바일에서는 지도 위, 목록 아래.
- 기본 UI·한국어 시스템 글꼴·초록색 저장 동작. 장식 이미지 없음.
- 중심 객체는 식당 위치와 출처. 식당명/주소/분석 근거를 같은 행에서 확인.
- 네비게이션: 내 지도 / 확인 필요. 새 링크는 한 가지 주요 동작.
- 상태: 빈 지도, 분석 중, 주소 검증 대기, 후보 선택, 저장 완료, 가져오기 실패, 권한 거부, 설정 미완료.
- 위치 권한은 주변 보기 버튼을 누를 때만 요청. 거부 시 기존 저장 목록 사용.
- 파일·본문은 분석에만 전송하고 서버에 저장하지 않음. 지도는 클라이언트 로컬에 저장.
- 접근성: 의미 있는 레이블, 키보드 조작, 44px 이상 터치 영역, reduced-motion, 텍스트 확대.

## 기술 검증 현황
- 제공한 두 공개 릴스 HTML을 실제 네트워크 요청으로 받아 본문 확보 성공.
- 첫 번째는 산와쇼텐/서울 마포구 토정로35길 6.
- 두 번째는 복수 식당과 비식당 광고가 함께 존재. 광고 제외가 필수.
- Xcode 미설치: iOS SDK 빌드/실기기 공유 확장 검증은 아직 불가.
- API 키 미연결: Gemini·카카오의 실 API 통합 검증은 설정 후 필요.
- 공개 HTML 접근 성공은 모든 릴스·클라우드 IP에서의 접근을 보장하지 않음.
