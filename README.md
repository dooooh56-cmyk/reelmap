# 릴맵 · 인스타 맛집 지도

한국 맛집 릴스를 공유해 식당을 추출하고, 저장해둔 식당을 현재 위치 주변에서 찾는 iOS 앱과 웹 체험판입니다.

**현재 상태:** 소스와 로컬 기능 검증이 준비되어 있습니다. Gemini는 결제 후 본문 및 표지 이미지 실제 분석이 성공했습니다. 본문 1건 847토큰, 본문+표지 이미지 1장 2,076토큰을 실측했습니다. 영상·음성은 아직 실측하지 않았습니다. 카카오 REST 검색은 활성화 후 실제 식당 조회가 성공했습니다. 배포 웹에서 본문을 추가해 산와쇼텐 자동 저장과 실제 지도 핀 표시를 확인했습니다. 클라우드에서 인스타 링크 직접 접근은 제한되어 본문·파일 보완이 필요합니다. iOS 앱과 공유 확장은 Xcode 27.1 시뮬레이터용 빌드가 성공했고, iOS 27.1 시뮬레이터에서 앱과 카카오 지도 표시를 확인했습니다. 실기기 서명·실행은 미검증입니다. 영상 분석과 실기기 공유까지 완료된 상태는 아닙니다.

## 구성

- `ios/ReelMap.xcodeproj`: SwiftUI 앱 + Share Extension (iOS 17 이상)
- `ios/Shared`: API 모델, App Group 저장, 공통 분석 화면
- `web/worker`: 로그인 없는 웹 UI와 Cloudflare Worker API
- `web/tests/core.test.mjs`: 장소 검증·입력 경계·오류 처리 검사
- `docs/SETUP.md`: 키 발급, 실행, iOS 서명 및 시연
- `docs/VERIFICATION.md`: 실제로 확인한 범위와 남은 검증
- `docs/DECISIONS.md`: 인터뷰 결정사항

## 동작

1. iOS 공유 메뉴의 ‘릴맵에 저장’, 또는 웹에서 인스타 링크 입력.
2. 공개 게시물 본문과 접근 가능한 영상 메타데이터를 가져옵니다. 접근할 수 없는 영상은 분석한 것으로 표시하지 않습니다.
3. Gemini가 본문부터 식당을 찾습니다. 모든 식당의 이름·주소가 확인되면 파일 분석을 생략하고, 부족하면 첨부 영상·사진으로 보완합니다. ‘첨부 파일까지 분석’을 켜면 파일을 직접 분석합니다.
4. 카카오 장소 검색에서 실제 음식점/카페와 좌표를 확인합니다.
5. 단일 식당의 이름·주소가 유일하게 일치할 때만 자동 저장합니다. 그 외에는 후보 목록에서 선택합니다.
6. 실패하면 ‘확인 필요’에 기록하고 추가 자료로 재분석하거나 직접 검색해 연결합니다.

자동 추출 결과에도 오류가 있을 수 있습니다. 특히 영상 속 동명 식당과 지점은 실제 자료로 통합 검증이 필요합니다.

## 로컬 웹 실행

Node.js 22 이상. 추가 패키지 설치 불필요.

```sh
cd web
cp .env.example .env.local
# .env.local에 키 입력 (버전 관리에 포함되지 않음)
bash scripts/build.sh
node scripts/dev.mjs
```

`http://localhost:8787`로 접속합니다. 스마트폰의 localhost는 Mac의 localhost와 다르므로 아이폰 체험에는 배포 URL을 사용하세요.

```sh
node tests/core.test.mjs
node scripts/validate-artifact.mjs
```

## 개인정보·비용

계정 없음. 식당/확인 필요 목록은 기기·브라우저에만 저장됩니다. 파일·본문은 Gemini로 전송되며 이 앱 서버는 보관하지 않습니다. 외부 제공자의 데이터 처리 정책은 별도로 적용됩니다. 위치는 기기에서 거리 계산에만 사용하며 서버로 보내지 않습니다. 웹은 백업/복원을 제공하고 iOS는 JSON 텍스트 백업을 제공합니다.

무료 할당량부터 사용하세요. **앱 자체가 누적 과금을 1만 원으로 차단하는 기능은 없습니다.** 유료 키를 사용할 경우 제공자 측 한도·결제 설정을 먼저 확인해야 합니다. 체험 코드는 공개 주소에서 API가 무단 사용되는 것을 줄이기 위한 설정입니다. 브라우저 계정 로그인과는 별개이며 키 자체를 대체하지 않습니다.

## 현재 추가된 기능

- 본문 우선 → 주소 검증 → 필요한 경우 파일 분석.
- 전체 파일 분석 옵션과 실제 AI 토큰 사용량 표시(입력·답변·추론·합계).
- 실제 본문+표지 입력에서 기본 모드는 903토큰, 전체 이미지 모드는 2,041토큰을 사용한 사례 확인. 매 요청 결과에 따라 달라집니다.
- 실제 MP4/MOV 릴스 영상의 자막·음성 검증은 원본 파일이 필요합니다. 공개 링크·임베드에서 영상 URL을 확보하지 못했습니다.
